## SSR과 robots

| 경로 또는 상황 | 이전 장애 | 로컬 후보 정상 / 장애 / 복구 |
| --- | --- | --- |
| 최근 마감 `/market/` 및 영문판 | 수치 없는 기본 개요 200 | 200 / 503 / 200 |
| 국·영문 공시 | 로딩 HTML 200 | 200 / 503 / 200 |
| 국·영문 용어집 | 오류 문구와 목록 없는 200 | 200 / 503 / 200 |
| 날짜별 시장 상세, 아카이브, 지표 | 503과 `noindex` | 200 / 503 / 200 |
| 경제 캘린더 이벤트 저장소 장애 | 거래일 일정과 장애 안내가 담긴 200 | 200 / 200 / 200 |

- 핵심 데이터를 읽지 못하면 현지화된 재시도 안내와 내부 탐색 링크를 제공한다. 503은 `Retry-After: 60`, `Cache-Control: no-store`를 사용한다. 동일 처리를 통과한 운영 호스트 모의 요청에 새 `noindex`가 붙지 않았고 Preview의 공통 호스트 정책은 유지했다. 새 오류 페이지는 GA4와 방문 추적 대상에서 제외된다.
- 발행된 최종 레코드가 없는 날짜, 주말과 미확정 날짜는 기존 404를 유지한다. 정상적으로 조회한 원천에 아직 데이터가 없으면 마켓 허브는 정적 개요 200, 공시는 빈 상태 200이다. 특정 기간·날짜 쿼리의 기존 브라우저 화면도 유지했다. 최종 레코드가 이미 존재하지만 JSON 또는 레코드 정합성이 깨졌으면 503으로 처리한다.
- 시장 상세의 수익률·시장 자금·장중 추이·이미지 메타는 보조 항목이다. 실패해도 최종 마감 기록을 제공할 수 있으면 200이다. 최근 마감의 보조 조회와 상세·아카이브의 ECOS 환율 보정이 지연되면 주어진 시간의 일부만 기다리고 정상 핵심 데이터로 반환한다. 캘린더 이벤트를 읽지 못해도 계산 가능한 거래일 일정을 제공한다. 핵심 내용이 빠진 시장 개요와 용어집 껍데기를 마지막 정상 수치·정의로 취급하지 않았다. 페이지별 기존 정상본 저장이 확인되지 않아 새 저장 계층을 도입하지 않았다. 최근 마감·공시의 기존 1.5초 SSR 데이터 제한을 용어 목록 자산 조회에도 적용했다. 시장 상세의 기존 제한을 유지했다.
- 공개 robots는 `/admin$`, `/admin/`, `/api/admin/`, `/api/auth/`를 지정한다. 공개 JS·CSS·데이터, 시장·공시의 공개 API, Daum 소유권 확인행과 canonical 사이트맵 선언은 유지한다.
- 관리자 호스트는 애플리케이션에서 robots의 GET/HEAD에 `Disallow: /`를 반환한다. 공개 호스트의 관리자 진입은 기존 307, 관리 호스트에서 미로그인 진입은 기존 302를 유지하고 두 리디렉션에 `noindex, nofollow`와 기존의 private no-store 정책을 적용한다. 로그인 HTML, 권한 검사, CSP, 정확한 Origin 검사, 발행·교정 경로의 접근 제어는 기존 정책을 사용한다.
- Cloudflare의 실제 관리자 robots는 Pages 로직과 다른 계층에서 관측됐다. 이번 후보는 기본 Preview 별칭만으로 관리자 운영 호스트의 관리형 조합을 확인할 수 없다. 승인 뒤 적용 전에는 Preview에서 호스트 로직을 격리해 검증하고, 이후 운영 승인 시 두 호스트의 실제 응답을 재확인한다. 관리형 지시가 애플리케이션을 가리거나 `Allow: /`와 충돌하면 Cloudflare 설정 변경은 별도 승인으로 넘긴다. robots 자체는 인증 수단이 아니다.

## 방문과 읽기 통계

- 새 페이지 로드의 스크롤은 0에서 시작한다. 브라우저가 신뢰한 휠·터치·스크롤 키 입력 뒤 1.5초 이내의 실제 포그라운드 이동을 기록한다. 이동 가능한 문서 길이를 분모로 사용하고 세션 최댓값을 보존한다. 해시 이동·위치 복원·레이아웃 변경만으로는 증가하지 않는다. 스크롤바 드래그, 일부 보조 기술 경로, 입력 구간과 우연히 겹치는 프로그램 이동은 측정 한계다.
- 포그라운드 체류는 화면이 보이고 포커스가 있는 시간이다. 숨김·블러에서 멈추며 뒤로 가기 캐시에서 복원하면 같은 페이지 세션을 이어간다. 사람의 독서 여부 판정에는 사용할 수 없다. UUID별 UPSERT는 중복 전송과 순서가 바뀐 이벤트에서도 누적값을 더하지 않고 각 최댓값을 보존한다. 새로고침·새 탭은 기존과 같이 별도 페이지 로드다. 기존 원시 행과 저장 형식은 유지했다.
- **확인된 자동화**는 Cloudflare가 검증한 봇으로 식별 가능한 별도 요청 증거가 있을 때만 해당한다. 검증된 Googlebot은 GSC 크롤링 통계에서 별도로 본다. **의심 자동화**는 기존 Cloudflare Web Analytics에서 `All traffic`과 `Bots excluded` 사이의 차이로 집계 수준에서만 관찰할 수 있다. 두 값의 차이를 자체 읽기 데이터에 적용하거나 확인된 봇으로 환산할 수 없다. **미분류**에는 현재 자체 읽기 세션이 해당한다. 자체 테이블에 이벤트 출처를 분류할 근거가 없고 Free의 세션별 봇 판정은 확인하지 못했다.
- 국가·기기·짧은 시간·UA·`navigator.webdriver`로 행을 제외하지 않았다. 입력 검사는 측정 대상인 스크롤에만 사용하며 봇 판정으로 해석하지 않는다. 추후 자체 통계에 자동화 제외 집계를 제공하려면 판별 신호의 신뢰성과 저장 방법을 먼저 검토하고 스키마가 필요할 경우 별도 승인한다. 수집 항목이나 서비스는 추가하지 않았다. [Cloudflare Free 봇 기능](https://developers.cloudflare.com/bots/plans/free/)

## Preview, 운영 승인 및 롤백

1. Preview 승인 뒤 최신 `origin/main`의 신규 발행·교정을 보존하면서 Phase 2C만 적용한다. Preview D1 격리, 쓰기 제한, `X-Robots-Tag`를 먼저 확인한다.
2. Preview의 정상 HTML, 공개 robots, 국·영문 탐색과 메타데이터, 관리자 세션 정책, 게시 UI, 301 및 사이트맵을 확인한다. 장애는 Preview 전용 고정본 또는 로컬 Workerd에서만 재현한다. 관리자 호스트 robots의 Cloudflare 관리형 조합은 별도 실제 호스트 확인 대상으로 남긴다. D1 고정본이 운영 사이트맵과 다른 경우 차이를 설명한다.
3. 같은 데이터센터에서 캐시 상태를 구분해 대형 국·영문 리포트와 기존 1102 표본, 사이트맵, 최근 마감의 최초 응답과 Tail CPU·wall·outcome을 비교한다. 공시·용어집의 장애 안내, 목적지와 복구도 재확인한다. 운영 단계에서는 인위적 장애나 부하를 주입하지 않는다.
4. 별도 Production 승인 뒤 실제 배포 SHA와 Smoke를 확인한다. 1102 증가, 정상 데이터의 503, robots 충돌 또는 관리자 접근 회귀가 확인되면 Phase 2C 커밋만 최신 main에서 revert하고 이후 발행·교정을 보존한다. 롤백 배포에서 원래 관리자·SSR·robots, Phase 1–2B, Cache Rule과 비용을 확인한다. 과거 브라우저에서 로드한 추적 자산이 잠시 공존할 수 있으므로 적용·롤백 UTC를 통계에 표시한다.

남은 검증은 Preview·Production의 Cloudflare CPU와 메모리, 관리형 robots 조합, 신규·기존 추적 버전이 공존하는 기간이다. 영문 수급 320px과 읽기 통계의 검증 가능한 자동화 분류 및 장기 색인 추세는 후속 항목으로 남긴다. 색인율이나 CTR 변화는 배포 후 관측으로 판단한다.
